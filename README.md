# Pratik Kumar — GTA Universe Portfolio 🎮

A Grand Theft Auto–themed personal portfolio for **Pratik Kumar** — B.Tech CSE (AI) student, AI/ML enthusiast and Python developer.

Built with **React 18 + Vite + Tailwind CSS**, with interactive GTA-style sections, sound effects and smooth animations.

## 🚀 Live demo

https://pratikeyyy.github.io/pratik-portfolio/

## 🛠️ Tech stack

- React 18, Vite 5
- Tailwind CSS, PostCSS
- lucide-react icons, canvas-confetti

## 💻 Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
